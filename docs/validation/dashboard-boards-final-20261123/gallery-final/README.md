# Galería final M17

Las 135 capturas PNG de este directorio proceden de una sola compilación local y muestran `Versión 202611231858`. Resoluciones: desktop 1440×900, laptop 1366×768, tablet 768×1024 y móvil 390×844. Incluye dos capturas del modal de validación con datos ficticios del mismo estudio: código PROCONT con área y ARAPA sin selector de área.

Las pruebas ejecutaron React y Chromium con Supabase/proveedores simulados; no hubo llamadas externas ni tickets reales. SHA-256, versión, viewport, solicitudes externas, artefactos y medición de scripts están en [gallery-manifest.json](../gallery-final-meta/gallery-manifest.json) y [browser-bundle.json](../gallery-final-meta/browser-bundle.json). Para resultados, limitaciones y distinción entre PostgreSQL local y remoto, ver [REPORT.md](../REPORT.md).
