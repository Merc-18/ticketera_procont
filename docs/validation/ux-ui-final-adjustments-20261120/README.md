Revisión: 20/11/2026. Base: `6533b277e9022bf3bb9a64bff02d2e4cdbfc52d5`.
Rama: `feat/ticketera-ux-ui-four-areas`. Versión de **todas** las imágenes: **Versión 202611201512**.

84 capturas originales de Chromium: 20 estados por cuatro resoluciones y cuatro evidencias
adicionales de escritorio. Las páginas se capturan completas, con el ancho de la ventana
indicada; su alto puede superar el viewport. Todas incluyen el pie nativo de versión.
No se editaron imágenes ni se añadió una versión artificial.

El frontend es un único build de producción servido por Vite Preview. Los servicios y datos
son ficticios, interceptados localmente mediante los mecanismos de prueba existentes.
La franja «ENTORNO LOCAL · DATOS FICTICIOS · servicios simulados» la añade el arnés de
capturas fuera de React; no pertenece a la aplicación publicada. No se hicieron logins,
subidas ni solicitudes contra servicios remotos.

La revisión manual incluyó portal, login normal, carga, formulario, seguimiento, dashboard,
Kanban, Tabla, Gantt y modal. Las comprobaciones automáticas recorrieron los 84 estados.
No se declara conformidad WCAG completa ni validación con lector de pantalla.
